Feasibility Report

I imagine the most difficult technical portion of my project will be coding the branching dialogue trees. I have been looking at ways others have implemented this in HTML and JavaScript, such as this Reddit post and this blog post. I also chatted with Zahra about any ideas she had on how to do this, and she pointed me towards flickgame, which is a website that allows you to create a branching pages depending on what color on the screen you click on. Additional libraries I have been looking at are JointJS, which allows you to create branching flowcharts, and Coherent Gameface, which is a game UI library.

These are all super interesting and gave me a good idea of the different possibilities for implementing the dialogue, but I think the most elegant and easiest way might be to use key value pairs in a JSON file and use async JS to load and display the data. I will have one JSON file that assigns a key to each dialogue blurb - for example, 1A, 1B, based on row and position. I will also have a second JSON file that uses the keys to map the relationships, e.g. if the user selects 1B, respond with 2C. Bill emphasized that there should be one record for each relationship, so there might be multiple records for each prompt if it branches into different options.

My immediate next steps will be to create the JSON files with the key-value pairs, and by next Tuesday, I aim to have the messaging functionality ready for user testing.
